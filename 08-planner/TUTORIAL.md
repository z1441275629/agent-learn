## 0. 问题：ReAct 的天花板

- 衔接 07：记忆解决「记得住」，调度解决「做得长」——任务一复杂，走一步看一步就开始兜圈
- ReAct（走一步看一步）vs plan-then-execute（先出地图再行军）各适合什么任务——我的对比数据在 §6
- 预埋三个核心问题：重试怎么保证幂等？子任务失败几次该扔掉整张计划？计划赶不上变化时谁说了算？

## 1. Planner：把复杂任务变成结构化计划

- zod schema 定义计划：步骤列表（id / 描述 / 依赖 / 状态 pending|running|done|failed）
- 计划生成：一次 LLM 调用产出 JSON——parseModelJson + zod 双保险（07 的教训：模型输出格式永远不可信）
- 计划常驻上下文：每次请求把**最新计划状态**注入 system——计划是 working memory 里的钉子，模型每一步都看得见地图（对比 07 的索引常驻：同一个模式的复用）
- 打勾更新：执行完一项改状态、重新注入——「你每天看的 todo 进度条」背后就是这套

## 2. Executor：逐项执行 + 重试 + replan

- 执行循环：取下一个依赖已满足的 pending 项 → 执行 → 打勾 → 下一个
- 失败重试：次数上限；重试前先问——**这个工具重跑一遍安全吗（幂等）？**
  - 幂等的（读类 / search）随便重试；非幂等的（write_memory、发消息、下单）重试 = 重复副作用——07 的审计日志就是现成证据
- replan 触发条件（想清楚再写码）：连续 N 次失败 / 执行中发现计划前提错了 / 全部 done 但任务没完成——把当前进度 + 失败原因喂回 planner 重新出图
- replan 也要有熔断：重规划本身连续失败 N 次就停，别无限套娃

## 3. 并发：无依赖的子任务并行

- 依赖图：互不依赖的 pending 项打进**同一个请求的多个 tool_calls**（07 循环里的 Promise.all + tool_call_id 配对早就在做，现在把它提到计划层用）
- 加速比：**由架构直接推出，不跑对照**——串行墙钟 ≈ Σ(各步延迟)，并行 ≈ max(并行批) + 后续步；token 两臂天然持平（每步隔离成本照付，System+Tools ≈1.2k/步的固定开销一份不少，历史两轮观测 9.8k vs 9.4k 基本持平）。此规模下 API 延迟抖动（±30%）会淹没 2 路并行的理论收益，跑对照是欠功率实验——结论不会比推导更可信
- 判断标准（本模块学到的）：**实验预算只花在直觉算不出的结论上**——06 截断掉不掉成功率（反直觉，测）、07 A/B 谁捕得多（先验未知，测）、08 并行快不快（算术，不测）
- 失效边界（届时才需要实测）：并发数高到触发 provider 限流/排队时，「并行=快」重新变成假设
- 并发坑预告：写类工具并发互相踩（07 里「Promise.all 并发写同名文件互相覆盖」的注释就是预告）；完成顺序 ≠ 提交顺序

## 4. 定时与后台

- cron.ts（进程内迷你 cron 守护，零依赖）：5 域表达式解析（`* | */n | n | a,b | a-b`）+ nextFire 逐分钟步进 + setTimeout 链调度
- 谁来算「下次触发」：暴力步进（教学版）vs 算术跳跃（生产版）——先对再快；「永不触发的表达式」是最阴的配置错误，注册时炸掉
- 错过的堆积怎么办（补跑 or 跳过）：**由幂等性决定，是 job 级配置**——巡检可补（跑十遍一样）、日报不补（补昨天的没意义）
- 后台长任务：fire 不 await + fire 内部全兜异常（07 #18 unawaited 钩子的老规矩）；完成通知 = 控制台 + job-audit.log 追加（appendAudit 同款）
- 真任务接线：memory-sweep——07 手动跑的巡检（test_dedup clean）→ 08 的定时任务，闭环；daily-brief 模板留位
- 时区坑：教学版本地时，生产用 UTC 或交给 orchestrator（cron + 夏令时经典雷区）
- cron 开发第一律：别靠真等——`list`/`next '<expr>'` 验证时间计算，`run <job>` 验证任务本身，调试用 `* * * * *`

## 7. 一句话总结（必填，用你自己的话）
planner 用每步隔离的固定开销（约 2.5 倍 token）买来可打勾、可重试、可重规划、可并发的结构——步骤多、可拆分、子任务独立的长任务用它；短链路任务裸 ReAct 更便宜：没有 planner 出图的开销，且天然共享上下文，不用手工交接。
