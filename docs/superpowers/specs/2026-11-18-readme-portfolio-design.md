# README 作品集门面改造 · 设计

日期：2026-11-18 ｜ 状态：已批准 ｜ 规模：小改动（README 重写 + 一个文件搬迁）

## 意图

仓库已公开在 GitHub（z1441275629/agent-learn），但首页还是 2026-09-26 的一阶段辅导计划（通篇"你"字口吻、进度打勾表），完全没反映仓库现状。面试官点进来 30 秒内应该看懂：这个人从零手写了 Agent 全链路，硬货在哪，怎么导航。

## 目标 / 非目标

- **目标**：README 变成作品集门面——一句话定位 → 亮点区（带证据与链接）→ 三阶段路线表 → 目录地图 → 关键文档；一阶段计划完整归档。
- **非目标**：不重写历史文档（PHASE1/2/3、PITFALLS 等原样保留）；不做英文版；不改任何代码。

## 方案选择

- **A. 成果优先（已选）**：第一屏就是硬货，三阶段压缩成一张表保留成长故事。
- B. 学习进化叙事：时间线讲故事，硬货要滚半屏才出现——对时间少的看客不利，否。

## 设计

1. **搬迁**：现 README 内容原样 `git mv` 语义搬至 `PHASE1.md`（实际是新建文件，README 被整体重写），与 PHASE2/PHASE3 命名对齐。
2. **新 README 结构**（中文，第一人称工程口吻）：
   - 标题 + 一句话定位：从零手写 Agent 全链路的学习与实战仓库，不用框架。
   - 亮点区 6 项，每项一行证据 + 链接：手写 ReAct（03-agent/）、自建 MCP Server + 裸 JSON-RPC 客户端（04-mcp/ + personal-agent/mcp-server.ts）、零 token 测试金字塔（tests/）、面试题库 99 题/必背 62（docs/interview/）、踩坑实录 65 条（PITFALLS.md）、在用的个人 Agent 工作台（personal-agent/）。
   - 三阶段路线表：一（01~05 ✅）/ 二（06~12 ✅）/ 三（13~16 🚧，宿主 personal-agent/）。
   - 并行线一节：langChain/（LangGraph 实践 S0~S10）、jobprep/（S9 毕业项目「AI 面试备战台」）、blogs/（4 篇深度文）、reviews/（学习复盘）。
   - 目录地图 + 关键文档（LLM_FUNDAMENTALS、AI_GLOSSARY、INTERVIEW_QA、PITFALLS、PHASE1~3）。
3. **我的取舍（可推翻）**：
   - 标题用「AI Agent 实验室」，不带"面试准备"——定位是"在造东西的实验室"而非"在备考"，题库作为亮点之一出现即可。
   - 数字写前逐一核实（题库 99/62、PITFALLS 条数、测试通过数），不凭记忆写。
   - 语气克制，只陈述事实与证据，不用形容词堆砌。
4. **PII 纪律**：新 README 不出现 key、套餐、账号、个人身份信息；提交前按仓库惯例自查。
