**关键升级点与真实时间线**（2026-11-15 用户口述校准）：蓝湖 2026.07 离职 → 7~9 月考教师资格证（9.12 结束）→ 9.20 起准备前端求职 → **10 月起全力投入 Agent 开发实践**（与仓库自述 09-26 开始一致）。因此实践口径锁定「**近 2 个月**」（11-10 草稿原本就是对的，「4 个月」是设计稿推算错误，废弃）；教资一段不进简历，只作面试口头解释。

蓝湖末期（2026.04-2026.07）有 AI 研发助手「龙虾」落地经验（Agent 配置/提示词调优/知识库接入/飞书企微微信多端机器人），但用户自评：**黑盒、基础、纯聊天式调优**——故定位为「**AI 助手落地经验 + 转向动机**」，不写成深度 Agent 工程；「发现自己是黑盒调优 → 离职从原理层系统重学」是简历与面试的核心故事线。更早的智化科技是 AI 制药公司背景。

## 目标 / 非目标 / 反目标

**目标**
- 题库：9 章 × 8~12 题 ≈ 90-100 题，市场向全科覆盖 + 项目深挖章；每题带背诵版答案与追问链
- 简历 AI 版：工作经历/教育填真、龙虾叙事进简历、数字全量重盘、补 LangChain/LangGraph 线 + jobprep 第三项目条目、定位改「原理手写 + 框架实战」双线
- 前端版 v2：不动

**非目标**
- 不改 jobprep / loader / 任何代码
- 不做前端岗八股题库
- 不产出 PDF（简历定稿后可另起任务）
- 不接入知识库/陪练

**反目标（做砸了长这样）**
- 题库变成百科全书：背不完、必背重点被淹没
- 简历出现无证据数字、把多租户 v2 写成生产经验（EVIDENCE 红线）
- PII 泄漏进 git

## 约束

**EVIDENCE 纪律**（自 resume-1page.md 删减说明注释固化，延续执行）：
1. 只写有仓库/提交/测试佐证的表述；无 before/after 基准的优化只讲机制不讲幅度
2. 多租户 v2 不写成生产经验（复盘结论：单人使用不实用，§8 终止）
3. 不绑定模型品牌名（写「多模型路由」「多模态」等能力口径）
4. 提交数/行数/套件数按实测重盘，沿用旧口径即是错

**PII 纪律**：`resume/` 整目录已在 .gitignore（永不入库）；题库在 `docs/interview/` 无 PII，正常提交。

**语言**：中文夹英文术语；代码示例 TS 优先（用户主力栈 TS + LangChain/LangGraph JS 生态）。

## 题库设计

**位置**：`docs/interview/`，README.md 索引 + 9 个章节文件。

**章节**（每章 8~12 题，共约 90-100 题）：
1. **LLM 基础与 API**：token/上下文窗口/sampling 参数/结构化输出/流式/多模态/幻觉成因与缓解/模型选型
2. **RAG 与检索**：chunking/嵌入/向量库/混合检索/rerank/RAG 评估/微调 vs RAG vs prompt 选型
3. **Function Calling 与 MCP**：工具 schema 设计/同轮并行调用/错误处理与重试/MCP 协议（stdio/版本协商/在途请求）/工具安全
4. **Agent 编排与 LangChain/LangGraph**：ReAct/Planner-Executor/多 agent 模式（supervisor vs handoff）/StateGraph/checkpointer/interrupt/框架 vs 自研 vs dify 类平台选型
5. **Prompt 与上下文工程**：system 设计/few-shot/CoT/上下文压缩与裁剪/记忆系统（短期/长期）
6. **生产工程化**：SSE 与断线重连/并发与限流/成本治理/延迟优化/缓存/部署
7. **评测与可观测**：eval 集设计/LLM-as-judge 与偏差/tracing/线上监控
8. **安全**：prompt injection（直接/间接）/tool poisoning/PII 处理/权限最小化/沙箱
9. **项目深挖与场景设计**：jobprep 三个工程决定/龙虾职业经验/personal-agent 机制深挖/PITFALLS 故事题/系统设计场景题（「设计一个 XX agent」）

**每题结构**：
```markdown
### Q1. 题目【必背★|进阶】
**背诵版**：要点式答案，面试可口述（100~200 字）
**追问**：Q：高频追问 → 一句话答
```

**分批**：批 1 = 第 1、2 章（LLM 基础 + RAG）交用户试读，格式认可后再铺剩余 7 章；批间可调格式，避免 100 题方向跑偏返工。
