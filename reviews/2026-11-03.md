## 2. 核心知识讲解

### ① 确定性任务与生成式任务的分工（以及双路线并存的设计）

**是什么**：OCR（把图片里的字读出来）是**确定性任务**——答案在输入里已经确定，只是提取；翻译、总结是**生成式任务**——需要理解后重新表达。两者对模型的容错要求完全不同。

**为什么**：LLM 会**幻觉**——尤其报坐标（bbox）时幻觉严重：它"觉得"字在哪个位置，跟实际像素位置对不上。对 OCR 来说，字识错一个就毁一行；而对翻译，模型"发挥"一点通常可接受。所以 OCR 交给确定性工具（tesseract），LLM 只做翻译。

**怎么用（双路线并存设计）**：本地 tesseract 快、免费、带坐标置信度，但语言包首次要下载；AI 视觉模型配置好就能用但慢、有配额、没坐标。两者并存的关键是**统一接口**：

```ts
// 统一 OcrResult：engine 标注来源，lines 带逐行信息
{ engine: 'local' | 'ai', text: string, lines: { text, bbox?, confidence? }[] }
```

差异**结构化**而不是抹平：本地有 bbox+confidence，AI 就缺这些字段（不伪造）。消费端（UI）按字段自动降级：没有 bbox 就不启用悬停高亮，没有 confidence 就不显示百分比。这样加一条新路线（比如换 Cloud OCR）不用改 UI。

**和什么相关**：接口隔离 + 降级设计的通用思路；也呼应「AI 配置缺失不许打死整个工具」——懒建客户端，哪条路坏了就只坏哪条路。

### ② 调参纪律：「参数被接受 ≠ 被执行」，用 usage 指标证伪

**是什么**：配置 `reasoning_effort: 'low'` 想关掉模型思考，返回的 usage 里 thinking token 仍是 551——参数被 API 接受了（不报错），但根本没生效。换成 `thinking: { type: 'disabled' }` 才降到 34 token，耗时从 10.7s 到 2.1s。

**为什么**：各家 LLM 平台对"思考开关"的协议不统一、且演进中：有的平台直接忽略你的参数，有的把它当最低档而不是关闭。只看请求参数"传了没"不可信，必须看**响应里的 usage 指标**（thinking_tokens、总 token 数、耗时）来证伪。

**怎么用**：改任何模型行为参数，都要先跑一条基线，再改参数跑对照，用 usage 数据说话；把这条记进 PITFALLS #37。这也是仓库里 `LLM_THINKING_STYLE` 三态约定（开/关/低）统一接入的原因——每个档位都验证过真实效果。

## 4. 参考答案

1. OCR 是**确定性任务**：答案已存在于输入，只需提取；LLM 会幻觉（尤其坐标），一个字错就毁一行。当时三条视觉 LLM 路全堵（平台不支持/端点未开/配额撞墙）是触发点，但根本判断是：识别交给确定性工具 tesseract（本地、免费、带坐标置信度），LLM 只做翻译这种生成式任务——还只翻 CJK 占比<30% 的非中文行，中文再翻既费钱又改坏专名。
2. 统一一个 `OcrResult`（engine/text/lines），差异**结构化不抹平**：本地有 bbox+confidence，AI 没有（LLM 报坐标是幻觉，宁可缺字段不伪造）。UI 按字段**自动降级**：无 bbox 不启用悬停高亮、无 confidence 不显示百分比。加新路线不改 UI，坏一条路不拖死另一条（懒建客户端，AI 配置缺失 AI 路线单独报错）。
3. ①宽容两种输出形状 `[{text}]` / `[..]`；②剥掉 ```json 代码围栏；③解析失败重试一次；④遇 502 返回「可切回本地」提示。engine 字段标记来源，AI 路线不带坐标。这条路径用 mock OpenAI 兼容端点全链验证过（日志证实图片真发出、围栏剥净）。
4. Server酱 32KB 上限，按**字节**截（UTF-8 中文 3 字节，不能按字符数），用 30KB 安全线；**截断保尾**——尾巴是链接（逃生门），微信内打不开还有电脑/系统浏览器可用，绝不把链接切掉；截在 UTF-8 多字节中间允许 1 个替换字符；组装逻辑提成纯函数，探针可测（160KB 压到 30061B 的断言）。
5. 不能只看「参数传了没」——reasoning_effort:'low' 被接受但 thinking token 仍 551，**参数被接受≠被执行**。必须跑基线对照，用响应 usage 指标证伪（thinking_tokens/总 token/耗时）：`thinking:{type:'disabled'}` 才从 10.7s/517 降到 2.1s/34。这条记进 PITFALLS #37，所有行为参数都按此验证。
