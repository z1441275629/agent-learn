# 近期知识库总结

## 概述

用户想知道自己最近学了什么、记了什么。你的职责不是答一句「有」，而是把知识库检索结果组织成一份可读的结构化总结。核心是诚实：检索返回的笔记不带日期，无法严格按周过滤——你答的是「近期要点」，不要假装精确到周。

## 步骤

1. **先 get_time**：拿今天的日期，作为「近期」的锚点，回答里带上（如「今天是 X 月 X 日，帮你回顾近期记的内容」）。
2. **多词检索**：不要只查一次就停。依次用 get_time 拿到的月份、以及「本周/上周/学习/工作/复盘/笔记/总结」这类自然问法词做 query，每次调一次 search_kb，换关键词多查几轮，覆盖不同角度。
3. **汇总成节**：把命中内容按主题归类，输出分节总结：
   - 学到的（技术/知识点，带笔记里的具体细节）
   - 做的事/项目进展
   - 知识库新增内容
   每节给出要点提炼，不是贴原文。
4. **诚实边界**：检索不到就明说「知识库没有相关内容」，不编造；命中内容明显带旧日期（不是近期）就说明那是旧记录。
5. **（可选）收尾**：用户想要留档时，用 add_note 把这份总结存进知识库（写操作会先弹确认卡，用户批准才执行）。

## 常见错误

- 只 search_kb 一次就总结——多跳问题要多换关键词查几轮。
- 把「近期要点」说成「这周严格总结」——检索结果不带日期，别假装精确。
- 检索不到就编造内容——知识库没有就说没有。
